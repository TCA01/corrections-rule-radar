# 형사소송법 조문별 비교출처 증거 보고서

형사소송법은 32개 개정·연혁 이벤트를 보유하며, 그중 10개는 법제처 공식 신구법 비교자료를 사용하고 22개는 법제처가 제공한 전후 구조화 원문을 프로그램이 조문 단위로 자동 비교한다.

법제처 공식 비교에서 검출된 조문 변경 발생 건수: **34건**

구조화 원문 자동 비교에서 검출된 조문 변경 발생 건수: **163건**

조문 변경 발생 총합: **197건**. 같은 조문이 서로 다른 이벤트에서 변경되면 각각 별도의 발생 건으로 센다. 이벤트 10건을 조문 10개로 해석하지 않는다. 변경 조문 0개인 이벤트도 이벤트 수에는 포함하며, 조문 발생 CSV에는 행을 추가하지 않는다.

## 비교 출처가 지정되는 수준

**COMPARISON SOURCE LEVEL: EVENT. 혼합 출처 이벤트: 0건.**

Comparison source is assigned at amendment/version-pair level, and the changed articles listed under that event inherit that source.

비교 출처는 개정 이벤트·버전 쌍에 한 번 지정되며, 그 이벤트의 변경 조문은 해당 출처를 따른다. [make_event](../../pipeline/diff/history.py#L95)는 단일 `source`를 정한 뒤 이벤트 최상위의 `comparison_source`에 기록한다. 각 `changed_articles[]` 원소에는 개별 비교 출처 필드가 없다. 공식 비교와 구조화 원문 비교를 한 이벤트 안에서 조문별로 섞어 생성하지 않는다.

저장 값 `LAWGO_OLD_NEW`는 표와 CSV에서 `OFFICIAL_OLD_NEW`로 표준화했다. `STRUCTURED_SNAPSHOT_DIFF`는 그대로 사용했다. 한글 표기는 각각 “법제처 공식 신구법 비교”, “공식 구조화 원문 자동 비교”다.

- 백엔드: [normalize.plain](../../pipeline/normalize/__init__.py#L26)에서 공식 구조화 API 본문의 표시 태그를 정리한다. [text_lines](../../pipeline/diff/articles.py#L11)는 조문·항·호·목 텍스트를 정해진 순서로 읽는다. [article_groups / article_diff](../../pipeline/diff/history.py#L24)는 조문 번호로 대응시켜 숫자 순으로 정렬하고, 문자열의 정확한 같음/다름으로 추가·삭제·수정·제목 변경을 결정한다.
- 백엔드의 공식 비교: [official_articles / make_event](../../pipeline/diff/history.py#L59)는 공식 신구법 API의 전후 법령·버전·시행일과 비교 본문을 검증해 우선 사용한다. 검증된 공식 비교를 사용할 수 없을 때 전체 구조화 원문을 비교한다. 공식 발췌와 전체 원문의 범위는 구별한다.
- 프런트엔드: [tokenizeLegalText / computeWordDiff](../../web/src/utils/diff.ts#L15)는 저장된 전후 문자열을 정규식으로 토큰화하고 동적 계획법 LCS로 화면에서 추가·삭제 단어를 강조한다. 어느 조문이 변경됐는지 결정하거나 이력의 조문 발생 수를 생성하는 과정이 아니다.

**LLM / generative AI used for legal diff determination: NO.** 비교 결정 경로에 OpenAI, ChatGPT, Gemini, Claude, LLM·임베딩 API 호출은 없다. 자동 비교 22개 이벤트를 오프라인 재계산해 저장된 변경 조문과 대조했다. 보고서를 작성하는 도구와 법령 변경을 결정하는 알고리즘은 구별한다.

## 검증 결과

32개 이벤트의 출처·조문 수·조문 목록을 기존 감사 CSV, 영구 이력, 공개 이력 및 개별 이벤트 파일과 대조했다. 모든 이벤트 ID는 `law-001671`에 속하며 중복 이벤트 ID와 혼합 출처 이벤트는 0건이다. 최근 90일의 두 2026-10-02 이벤트도 이력과 동일하다. CSV는 UTF-8 BOM, 9개 열, 헤더를 제외한 197개 발생 행이며 공식 34행·자동 163행이다. 전역 조문 번호 중복을 제거하지 않았다.

생산 동기화·API 조회·배포는 실행하지 않았다. 읽은 생산 자료, 기존 감사표 및 코드 77개 파일의 작업 전후 SHA-256이 동일함을 확인했다. 새 보고서와 새 CSV만 작성했다.
