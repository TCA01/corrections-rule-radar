법제처 공식 신구법 비교: 10

원문 출처: 법제처 국가법령정보센터 공식 구조화 API

공식 신구법 비교 데이터가 제공되는 경우 이를 우선 사용하고, 제공되지 않는 경우 국가법령정보센터의 두 공식 구조화 원문 버전을 조문 단위로 결정론적으로 비교한다. 공식 데이터는 전후 법령 ID·버전 ID·시행일과 비교 본문을 검증한 뒤 사용한다. 전후 쌍이나 본문 검증이 실패하면 구조화 원문 비교로 대체한다.

`LAWGO_OLD_NEW`를 이 보고서에서 `OFFICIAL_OLD_NEW`로 표시했다. `STRUCTURED_SNAPSHOT_DIFF`는 그대로 표시했다. 날짜로 출처를 추정하지 않았다. 두 분류 모두 저장된 `comparison_status=AVAILABLE`이며, 이 상태값만으로 공식 비교 여부를 구분하지 않는다.

대상: 형사소송법 (`law-001671`). 확인 기준일: 2026-10-04. 데이터 버전: `ds-ad3e2e2e1e7022e1725ced2003bb82c7ff4508408f1d9356218112235e66d590`.

## AI 미사용과 비교 구현

- [normalize.plain](../../pipeline/normalize/__init__.py#L26)은 공식 API 문자열의 표시 태그를 제거하고 구조화 본문을 유지한다. HTML 페이지를 수집하거나 법률 문장을 생성하지 않는다.
- [text_lines](../../pipeline/diff/articles.py#L11)는 `조문내용`, `항내용`, `호내용`, `목내용`, `내용`, `항`, `호`, `목`을 정해진 순서로 읽고 공백을 정리한다.
- [article_groups / article_diff](../../pipeline/diff/history.py#L24)는 조문 번호(예: `200의4`)로 원문을 대응시킨다. 번호의 합집합을 숫자 순서로 정렬하고 전후 문자열의 정확한 일치 여부를 비교해 `ADDED`, `REMOVED`, `MODIFIED`, `RENAMED`를 기록한다.
- [make_event / official_articles](../../pipeline/diff/history.py#L95)는 검증된 공식 신구법 API 비교를 먼저 시도하고, 비교 불가 시 위 원문 비교를 실행한다. 공식 비교의 범위는 `OFFICIAL_COMPARISON_EXCERPT`, 자동 비교의 범위는 `FULL_STRUCTURED_BODY`다. 공식 발췌의 생략 표시와 두 범위의 차이는 유지된다.
- [공식 비교 수집](../../pipeline/law_api/comparisons.py#L4)과 [일회성 이력 수집](../../scripts/backfill_history.py#L18)은 Law.go.kr `oldAndNew` 구조화 API를 사용한다. 비교 생성 경로에 OpenAI, ChatGPT, Gemini, Claude, LLM 또는 임베딩 API 호출은 없다.
- [화면 내 단어 강조](../../web/src/utils/diff.ts#L31)는 정규식 토큰화와 동적 계획법 LCS를 사용한다. 이는 화면에서 이미 저장된 전후 문장을 강조하는 처리이며, 이력 이벤트의 조문 수를 생성하는 방식과 구별된다.

자동 비교 22건 모두 저장된 전후 공식 스냅샷을 실제 `article_groups`·`article_diff`에 다시 넣어 저장된 `changed_articles`와 정확히 일치함을 오프라인으로 확인했다. 이 비교 알고리즘의 AI 사용은 NO다. 보고서 작성에 사용한 도구와 법령 비교 알고리즘은 구별한다.
